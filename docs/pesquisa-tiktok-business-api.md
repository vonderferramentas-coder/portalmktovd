# Pesquisa: existe uma API oficial do TikTok para ler dados da própria conta (fora do Login Kit)?

> Nota sobre o local do arquivo: não existe convenção prévia de "notas de pesquisa" neste repositório. Optei por `docs/pesquisa-tiktok-business-api.md`, ao lado de `docs/ARQUITETURA-E-INTEGRACOES.md`, porque o assunto é diretamente uma continuação da seção 15 desse documento (rejeição do App Review do Login Kit) e deve ser lido junto com ela. Se a equipe preferir um diretório `docs/pesquisas/`, mover este arquivo é trivial.

Data da pesquisa: 17/09/2026. Contexto: `docs/ARQUITETURA-E-INTEGRACOES.md`, seção 15 — TikTok Login Kit rejeitado em App Review por ser "não aceitável" exibir, no próprio site, dados de conta(s) que a própria equipe administra.

## Resumo executivo

**Inviável para o nosso caso, nas condições atuais.** Toda a família de produtos hospedada em `developers.tiktok.com` (Login Kit, Display API, Content Posting API) está sob as mesmas *Developer Guidelines*, que proíbem explicitamente apps limitados a "uso interno" ou "gerenciar a(s) conta(s) que você ou sua equipe administra" — não é uma peculiaridade do Login Kit, é política de toda a plataforma de developers, então trocar de produto dentro desse domínio não resolve. Existe sim uma API separada — a **TikTok Business API** (`business-api.tiktok.com`, também chamada TikTok for Business/Marketing API) — voltada a marcas gerenciarem os próprios ativos, mas ela é estruturada em torno de **Business Center + anúncios**; o acesso amplo a métricas orgânicas (seguidores, vídeos) por essa via, sem ser um parceiro certificado, não está documentado como self-service. O caminho realista que **de fato expõe métricas orgânicas de conta própria** sem que a agência precise virar parceiro certificado é um agregador terceirizado já credenciado — **Supermetrics tem um conector dedicado "TikTok Organic"** que devolve exatamente os campos que faltam no painel (seguidores, novos seguidores/dia, views/likes/comentários/compartilhamentos por vídeo), com login self-service usando as credenciais do próprio app TikTok da marca. É a opção mais concreta, mas depende de assinatura paga da Supermetrics e de logar com a conta oficial `@vonderferramentas` numa ferramenta terceira — uma decisão de produto/segurança, não só técnica. Recomendação: manter o lançamento manual (`source: manual`) como caminho vigente e só investir em Supermetrics se o orçamento/decisão de produto justificar.

## 1. Existe um produto oficial diferente do Login Kit para ler estatísticas da própria conta?

**Existe, mas não é "diferente" no sentido que resolveria o problema — é preciso separar dois domínios distintos de produto do TikTok:**

- **`developers.tiktok.com`** (Login Kit, Display API, Content Posting API, Research API): todos regidos pelas mesmas *Developer Guidelines*. A [página de overview do Display API](https://developers.tiktok.com/docs/en/display-api-overview) descreve o produto como forma de "influencers exibirem seus perfis e vídeos do TikTok para enriquecer conteúdo e atrair mais audiência" em produtos de terceiros — ou seja, pensado para que **criadores externos** autorizem **o app de alguém** a mostrar o perfil deles, não para uma empresa exibir os próprios dados. As [Developer Guidelines](https://developers.tiktok.com/docs/en/our-guidelines-developer-guidelines) deixam isso explícito de forma geral (não restrito ao Login Kit): "API Clients must not be limited to test applications and should be intended for a wide audience, not limited to internal groups/private use", e cita como exemplo de app **não aceitável** "a utility tool to help upload contents to the account(s) you or your team manages" — a mesma frase estrutural que motivou a rejeição do nosso Login Kit, agora comprovadamente aplicada a todo o guarda-chuva de produtos de developer, incluindo o Content Posting API (usado para postar, não para ler estatísticas) e o Display API (usado para exibir perfil/vídeos de terceiros). Portanto, trocar de escopo/produto dentro de `developers.tiktok.com` **não contorna a restrição**: a barreira é o modelo (app de terceiro + usuário final autoriza), não o escopo específico pedido.
- **`business-api.tiktok.com`** ("TikTok API for Business" / TikTok Marketing API): é de fato um produto **separado**, hospedado em domínio e portal próprios, "voltado a marcas administrarem os próprios ativos" — mas seu eixo é **Ads Manager, Business Center e TikTok One Creator Marketplace**. A busca não encontrou documentação de um endpoint self-service equivalente a "leia o `follower_count` da sua própria conta orgânica" fora do contexto de contas vinculadas a anúncios/Business Center; um resultado de terceiro (busca agregada, sem fonte primária TikTok) menciona que follower/following/likes/vídeo count "estão disponíveis via Business API (para sua própria conta business) ou provedores de dados terceirizados" — mas não achei o endpoint correspondente na documentação oficial (o portal de docs em `business-api.tiktok.com/portal/docs` é uma SPA que não expôs conteúdo textual navegável nesta pesquisa; ver limitação abaixo). Não há confirmação de fonte primária de um endpoint dedicado a estatísticas orgânicas (visualizações/curtidas/comentários/compartilhamentos de vídeo) fora do fluxo de anúncios.

**Limitação desta pesquisa:** o portal `business-api.tiktok.com/portal/docs` é renderizado via JavaScript client-side; as tentativas de leitura direta da doc (WebFetch) retornaram apenas o título da página, sem o corpo do texto. A caracterização da Business API acima é reconstruída a partir de resultados de busca (snippets do Google/Bing sobre essas páginas) e não de leitura direta do texto integral da documentação — é o ponto mais fraco desta pesquisa e merece confirmação manual (abrir `business-api.tiktok.com/portal/docs?id=6` num navegador) antes de qualquer decisão de investir esforço de engenharia nessa rota.

## 2. Requisitos de acesso à TikTok Business API

- **Certificação/parceria:** a TikTok mantém um programa formal, o **[TikTok Marketing Partners](https://partners.tiktok.com/)**, com [badges por especialidade](https://ads.tiktok.com/business/en/blog/badged-agency-marketing-partners) incluindo uma categoria **"Measurement"** (atribuição, analytics e marketing mix modeling). Um resumo de terceiro sobre o processo descreve exigências como "expertise comprovada com histórico na especialidade" e "capacidade técnica (integração via API, conformidade de plataforma)", com aprovação levando tipicamente 2–4 semanas — mas não achei uma página oficial da TikTok detalhando os critérios exatos de aceite ou custo de badge "Measurement" (o [Partner Directory oficial](https://partners.tiktok.com/directory/pc/en?specialties=2) lista quem já tem o badge, não os requisitos para obtê-lo).
- **Conta TikTok Business vinculada a um Business Center:** documentação de suporte da própria TikTok Ads confirma que operações de conta via Business Center exigem papéis de administrador (Owner/Admin/Operator) e, para Business Centers registrados em US/EU/UK, **Verified Business Account** — ver [How to add partners to your Business Center](https://ads.tiktok.com/help/article/invite-partners-into-tiktok-business-center?lang=en) e a nota (via busca) de que Business Centers dessas regiões "must have a Verified Business Account".
- **Processo:** aparentemente não é puramente self-service para o caso de uso de "ler dados orgânicos" — o modelo institucional do TikTok para acesso amplo a dados agregados/orgânicos por terceiros passa pelo badge de parceiro "Measurement", que é avaliação qualificada da própria TikTok, não um simples cadastro de app como o Login Kit.

## 3. É viável para uma agência pequena/média (não parceira certificada)?

**Não, para a rota de "virar parceiro certificado e consumir a Business API diretamente".** As evidências apontam que o badge "Measurement" do programa TikTok Marketing Partners é dirigido a fornecedores de tecnologia de analytics/atribuição com histórico e escala comprovados (é assim que Supermetrics e Metricool acessam dados oficiais — ver seção 4), não a agências de marketing operando o próprio painel interno para poucos clientes. Não há evidência de um nível "starter"/self-service da Business API que devolva estatísticas orgânicas de conta sem essa camada de parceria — o que a documentação de suporte da TikTok Ads descreve como self-service (convidar parceiros num Business Center, dar papéis de acesso) é sobre **gestão colaborativa de contas de anúncio**, não sobre **exportar métricas orgânicas via API própria**.

**Sim, para o caso de uso adjacente** de uma agência gerenciar a conta de anúncios (Ads Manager) de um cliente dentro do Business Center dele — isso é o fluxo padrão e documentado (convite de parceiro, papéis de acesso) — mas não é o que precisamos aqui (não há investimento em TikTok Ads pago, o objetivo é ler seguidores/estatísticas orgânicas).

## 4. Agregador terceirizado com acesso já aprovado a dados orgânicos do TikTok

**Sim — Supermetrics tem um data source dedicado, "TikTok Organic", separado do "TikTok Ads".**

- Existência e escopo: a página de produto ["TikTok Organic Data Connector & Integration"](https://supermetrics.com/connectors/tiktok-organic) descreve o conector como voltado ao "desempenho orgânico da própria conta" ("profile views, video views, likes, reach, and so much more"), distinto do conector ["TikTok Ads"](https://supermetrics.com/connectors/tiktok-ads) (esse sim focado em campanhas pagas, integrando TikTok Ads a BigQuery/Looker Studio/etc.).
- Campos expostos: a página de referência ["TikTok Organic metrics and dimensions"](https://docs.supermetrics.com/docs/tiktok-organic-fields) lista, entre outros: **Current Followers** ("Current total number of accounts following this profile"), **New Followers** (por dia), **Video Views**, **Likes** (nota: "does not subtract unlikes"), **Comments**, **Shares**, **Profile Views**, além de métricas por vídeo individual (views/likes/comments/shares, reach, favorites, watch time, completion rate) e distribuição demográfica de seguidores por país/gênero (agregado de 60 dias, para contas com 100+ seguidores). Isso cobre exatamente os campos que faltam no nosso painel: `follower_count` e `view_count`/`like_count`/`comment_count`/`share_count` por vídeo.
- Requisitos de conexão: o ["TikTok Organic connection guide"](https://docs.supermetrics.com/docs/tiktok-organic-connection-guide) afirma que a conexão aceita conta TikTok **Business ou Personal** (para Personal: mínimo de 100 seguidores, analytics habilitado, ao menos 1 post público); o login é feito "com as mesmas credenciais usadas para logar no perfil TikTok no app mobile" — ou seja, **self-service do lado do cliente/agência**, sem exigir que a própria agência vire parceira certificada da TikTok (é a Supermetrics que já detém esse acesso institucional, presumivelmente como parceira). O mesmo guia adverte que não é possível puxar dados de outra conta mesmo com permissões concedidas no TikTok — teria que ser a própria conta `@vonderferramentas` fazendo login na Supermetrics.
- Alternativa equivalente: **Metricool** também anuncia (via busca, não confirmado com fetch direto de fonte primária) que "os dados do TikTok vêm da API oficial do TikTok e correspondem à atividade orgânica do perfil", com mais métricas disponíveis para contas Business do que Personal, e aparece listada no [TikTok App Center](https://ads.tiktok.com/apps_and_agents/app-center/detail/Metricool/7342550986344398850) — sinal de que é uma integração oficialmente credenciada, no mesmo padrão da Supermetrics.

**Trade-offs práticos dessa rota (não uma questão de viabilidade técnica, e sim de produto/segurança/custo):**
1. **Custo:** Supermetrics e Metricool são produtos pagos por assinatura (não há tier gratuito para conectores de API/exportação); adicionaria uma despesa recorrente só para preencher um card do painel.
2. **Compartilhamento de credencial:** o login "com as mesmas credenciais do app mobile" significa autenticar a conta oficial `@vonderferramentas` (ou equivalente) dentro de uma ferramenta terceira — implica avaliar quem passa a ter esse acesso e como revogar se necessário.
3. **Integração de dados:** mesmo aprovando o uso de um agregador, ainda seria preciso um passo de engenharia para puxar os dados da Supermetrics/Metricool (API própria delas, ou exportação agendada para planilha/BigQuery) e alimentar `followers-dashboard.js`/`data/social-followers-live.json` — não é um substituto direto "plug-and-play" do workflow GitHub Actions que já existe para Instagram/Facebook/YouTube.

## Recomendação final

**Manter o lançamento manual do TikTok como caminho vigente** (`source: manual`, conforme já implementado em `data/social-followers-live.json` e documentado em `docs/ARQUITETURA-E-INTEGRACOES.md` seção 15). Não recomendo reabrir esforço de engenharia para integrar diretamente com `developers.tiktok.com` sob nenhuma variação de escopo/produto — a barreira é estrutural e documentada em toda a plataforma de developer (Login Kit, Display API e Content Posting API compartilham a mesma proibição de "uso interno"/"gerenciar a própria conta"), reenviar ou trocar de produto nesse domínio não muda o desfecho.

Se, no futuro, a diretoria quiser reabrir a coleta automática do TikTok, o único caminho concretamente viável encontrado nesta pesquisa é **avaliar uma assinatura da Supermetrics (conector "TikTok Organic") ou da Metricool** como atalho — ambas já teriam o acesso institucional que nós não conseguiríamos sozinhos numa escala pequena/média — aceitando o custo recorrente e a necessidade de logar a conta oficial da marca numa ferramenta terceira. Antes de comprometer orçamento, vale confirmar manualmente (login real numa conta de teste) se o plano de entrada da Supermetrics/Metricool realmente inclui o conector orgânico do TikTok e a que preço, e decidir se essa despesa se justifica só para automatizar um número que hoje é lançado manualmente com baixo esforço. A via de "virar TikTok Marketing Partner" (badge Measurement) para acesso direto à Business API não é recomendável para o porte desta agência — está desenhada para fornecedores de tecnologia de analytics em escala, não para uma agência com uma carteira de marcas como a nossa.
