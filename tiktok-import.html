Importar histórico do TikTok Studio

O TikTok não tem API oficial liberada pra esse uso (App Review rejeitado — ver docs/ARQUITETURA-E-INTEGRACOES.md seção 15). O caminho oficial que sobrou é este: baixe o histórico direto do TikTok Studio (Análise → Seguidores → Baixar dados → escolha CSV), extraia o arquivo FollowerHistory.csv do zip baixado, e selecione-o abaixo.

A importação mescla só o número de seguidores do TikTok por dia — nunca apaga ou altera Instagram, Facebook ou YouTube dos mesmos dias, e nunca remove dias já existentes fora do período do arquivo.

Selecione o arquivo FollowerHistory.csv para começar.
